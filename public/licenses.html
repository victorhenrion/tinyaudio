To rebuild LAME WebAssembly, extract the wrapper archive and place the LAME source in src/wasm/lame/lame-src. Follow the wrapper README and Makefile with Emscripten to run make prod. The MP3 WASM is a separate asset and can be replaced with a compatible rebuilt module. See source and build notes.
